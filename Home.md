# ani-cli — VVAT3R Fork

A POSIX shell script to browse, watch, and download anime from the terminal. Uses **anidb.app** as the primary source — no Python, no Botan dependency.

## Features

- Search and stream anime from anidb.app
- Download episodes (aria2c, ffmpeg, or yt-dlp)
- Resume playback from saved position
- Batch download entire series
- Choose quality (360p, 720p, 1080p)
- Skip intros (with ani-skip)
- History tracking
- Syncplay support to watch with friends

## Quick Install

```sh
curl -sL https://raw.githubusercontent.com/VVAT3R/ani-cli/master/install.sh | bash
```
